개인정보 처리방침

LoL 밴픽대전 시뮬레이터 · 시행일 2026-11-12

1. 수집하는 정보

사이트는 정적 교육용 웹사이트로, 회원가입·로그인 기능이 없고 Riot 계정 로그인도 요구하지 않습니다. 방문자의 이름, 이메일, Riot ID 등 개인정보를 입력받거나 수집하지 않습니다.

2. 쿠키와 분석 도구

사이트는 쿠키, 광고, 방문 분석(애널리틱스) 도구를 사용하지 않으며 브라우저 저장소에 정보를 남기지 않습니다. 글꼴과 이미지는 모두 사이트 안에서 제공되어 외부 서비스로 요청을 보내지 않습니다. 밴픽 진행 내용은 사용 중인 브라우저 화면 안에서만 처리되고 서버로 전송되지 않습니다.

3. Riot Games API 데이터

방문자의 브라우저에서는 Riot Games API를 호출하지 않습니다. 별도의 오프라인 수집 프로그램이 Riot Games API로 한국 서버의 공개 랭크 경기 데이터를 받아 챔피언 상성과 포지션별 시너지 통계(경기 수 포함)로 집계하며, 사이트에는 이 집계값만 표시합니다. 이 통계는 챔피언과 포지션에 관한 것이며 개별 플레이어나 방문자의 프로필이 아닙니다.

4. 호스팅

사이트는 GitHub Pages에서 제공됩니다. GitHub는 IP 주소 등 일반적인 접속 기록을 GitHub의 개인정보 처리방침에 따라 처리할 수 있습니다. 운영자는 방문자 정보를 판매하지 않으며, 사이트를 도박이나 광고에 사용하지 않습니다.

5. 변경

이 방침이 바뀌면 이 페이지를 갱신합니다.

6. 문의

연락처: 운영자(홍승표, 신구대학교 e스포츠과) 이메일은 확인 후 이 자리에 기재할 예정입니다.

Privacy Policy

LoL Ban/Pick Simulator · Effective 2026-11-12

1. Information we collect

The Site is a static educational website. It has no accounts or login, and it never asks visitors to sign in with a Riot account. It does not ask for or collect names, emails, Riot IDs, or other personal information from visitors.

2. Cookies and analytics

The Site uses no cookies, advertising, or analytics tools, and stores nothing in browser storage. Fonts and images are served from the Site itself, so no requests are sent to third-party services. Draft progress is handled only within the visitor's browser page and is not sent to any server.

3. Riot Games API data

The Riot Games API is not called from the visitor's browser. Separately, an offline collector uses the Riot Games API to download public ranked League of Legends match data from the Korean server and aggregates it into champion matchup and position-synergy statistics (including game counts). Only these aggregates are shown on the Site. They describe champions and roles, not individual players or visitors.

4. Hosting

The Site is hosted on GitHub Pages. GitHub may process ordinary technical logs such as IP addresses under GitHub's own privacy policy. The operator does not sell visitor data and does not use the Site for betting or advertising.

5. Changes

If this policy changes, this page will be updated.
