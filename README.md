# lol-banpick-lab — source branch

The live site (GitHub Pages) is the built output on `main`. This branch holds the source and the collected data.
No API keys, passwords or player identifiers are included.

## Folders
- `web/` — site source (Vite + React + TypeScript). `npm install` → `npm run build` → copy `dist/` to the root of `main` (keep `riot.txt`, `.nojekyll`, `data/`).
  - `src/ranked.ts` is generated by `collector/make_site_data.py` (do not edit by hand). `src/pro.ts` is generated by `collector/make_pro_data.py` from the Oracle's Elixir 2026 CSV (not included here; download it from Oracle's Elixir).
- `collector/` — Riot API collector (Python 3.11+, standard library only).
  - `collect.py` reads the key from `~/.riot/api_key.txt` (never commit it). KR ranked solo (queue 420), games >= 15 min, MATCH-V5 + timeline.
  - `make_site_data.py` → `web/src/ranked.ts` (tier 3 = Master+, tier 2 = Emerald+). `build.py` → matchups.json.
- `data/matches.jsonl` — one KR ranked game per line, deduplicated by match id (snapshot 2026-11-16 10:56 KST, 41,361 games:
  Challenger 2,678 · Grandmaster 5,183 · Master 11,000 · Diamond 11,000 · Emerald 11,500; tier = ladder of the player the game was found through).

## matches.jsonl fields
- `id` match id, `v` game version (16.22 = patch 26.22), `t` tier, `dur` seconds
- `p` 10 rows: `[teamId, lane(T/J/M/A/S), championName, win(1/0), gold@15, level6 sec, first legendary item sec, first legendary item id]`
- `g` (timeline): `obj` = `[monsterType, subType, killerTeamId, sec]`, `jg` = per team jungler `{path: lanes at 2/3/4 min, fk: [sec, lane, 1=kill/assist 0=death]}`, `ft` = first tower `[teamId that took it, sec, lane]`
